# WiFi 连接管理 Skill

通过 NetworkManager (`nmcli`) 管理设备的 WiFi 连接。

## 功能

| 工具 | 功能 | 示例指令 |
|------|------|---------|
| `wifi_scan` | 扫描附近 WiFi | "扫描wifi"、"附近有哪些网络" |
| `wifi_connect` | 连接指定 WiFi | "连接 MyWiFi"、"接入 office_5G" |
| `wifi_disconnect` | 断开当前连接 | "断开wifi"、"断网" |
| `wifi_status` | 查看连接状态 | "当前wifi状态"、"连的什么网络" |

## 依赖

- **nmcli** (NetworkManager CLI) — 大多数 Linux 桌面发行版预装

检查是否已安装:
```bash
which nmcli
```

## 工作原理

### 三段式路由适配

本 Skill 遵循 bibit 的三段式路由设计:

1. **规则引擎**（第一段）— `skill.yaml` 的 `routes.rule.patterns` 定义正则,
   高频指令（如"扫描wifi"）零成本命中
2. **端侧模型**（第二段）— `routes.local` 提供精简签名（如 `wscan()`）,
   口语化表达由 1.7B 模型识别
3. **云端**（第三段）— 复杂场景（如"帮我连一个信号最好的网络"）升级云端

### 安全设计

- **参数化执行** — 所有 `nmcli` 调用用列表形式,绝不 shell 字符串拼接,防注入
- **密码保护** — WiFi 密码不回显、不写日志
- **超时控制** — 连接操作 30s 超时,避免卡死

## 使用示例

```bash
# 扫描网络
bibit "扫描wifi"
# → 扫描到 5 个网络
#   MyHome (信号85, WPA2)
#   office_5G (信号72, WPA2)
#   ...

# 连接网络（推荐规整表达）
bibit "连接 MyHome"                    # 开放网络
bibit "连接 MyHome 密码 12345678"       # 带密码

# 查看状态
bibit "当前连的什么wifi"
# → 当前连接：MyHome（信号 85）

# 断开
bibit "断开wifi"
# → 已断开 WiFi（设备 wlan0）
```

## 表达方式与能力边界

WiFi 连接**推荐使用规整表达**，规则引擎可 100% 准确抽取 SSID 和密码：

| 表达 | 处理层 | 准确性 |
|------|--------|--------|
| `连接 JDSK 密码 12345678` | ①规则引擎 | ✅ 100% |
| `连接 JDSK`（开放网络） | ①规则引擎 | ✅ 100% |
| `接入 office_5G 密码 secret` | ①规则引擎 | ✅ 100% |

**不推荐的倒装/口语表达**（端侧 1.7B 模型可能混淆参数）：

| 表达 | 问题 |
|------|------|
| `JDSK的密码是xxx` | 模型可能把 SSID/密码对应错（倒装无"连接"动词） |
| `帮我连一下那个网` | 缺少明确 SSID，无法确定目标 |

**设计取舍**：端侧 1.7B 模型在参数对应关系上能力有限。对于 WiFi 连接这类
**参数敏感**（连错网络、密码填错位）的操作，引导用户使用规整表达，
由规则引擎确定性处理，比依赖模型猜测更可靠、更安全。

复杂或歧义场景可升级云端（第三段）由大模型处理。

## 安装

Skill 通过 bibit 的 Skill 加载机制注册:

```bash
# 复制到 skills 目录（或通过 skill 市场安装）
cp -r skills/wifi /path/to/bibit/skills/

# bibit 启动时自动扫描 skills/ 目录并加载
```

## 扩展方向

- **信号最优连接** — "连一个信号最好的" → 扫描后自动选择
- **已保存网络** — 记住历史连接,一键重连
- **网络诊断** — 连接失败时诊断原因（密码错误/信号弱/DHCP 超时）
