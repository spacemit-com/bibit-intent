# 意图识别用例:升级云端（端侧无能力）

**对应产品需求**: §4.3 复杂工作、§3.3 文件系统、§3.4 工作助理、§3.5 开发助手  
**场景**: 端侧无对应能力，应识别并升级到云端（escalate）  
**核心**: 让模型学会"识别自己搞不定 → 升级"，而非硬凑工具

## 字段说明

- **输入**: 模拟真实用户的口语表达
- **期望路由**: 本类几乎全为 `escalate`
- **期望工具**: 通常 None（升级由云端决策）
- **期望参数**: `-`
- **说明**: 升级原因（open_question / unsupported_control / 复杂任务）

## 混淆/边界用例（防止该升级的没升级、不该升级的乱升级）

| 输入 | 期望路由 | 期望工具 | 期望参数 | 说明 |
|------|---------|---------|---------|------|
| 音量调到60 | rule_call | set_volume | level=60 | 端侧能做，**不该**升级 |
| 扫描wifi | rule_call | wifi_scan | - | 端侧能做，不该升级 |
| 打开终端 | rule_call | launch_app | app_name=终端 | 端侧能做，不该升级 |
| 帮我写个关闭音量的脚本 | escalate | - | - | 生成脚本≠直接调音量工具，升级 |
| 把音量调到60并写下来 | escalate | - | - | 复合任务（执行+记录），超端侧单步能力 |
| 连接WiFi然后打开浏览器再搜索新闻 | escalate | - | - | 多步复杂编排，升级 |
